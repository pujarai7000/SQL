# SQL Data Manipulation Analysis

## Project Overview

This project demonstrates SQL data manipulation techniques using customer and order datasets. The analysis focuses on customer activity, order behavior, categorization, aggregation, and subqueries.

## Skills Practiced

- CASE Statements
- COUNT()
- AVG()
- GROUP BY
- HAVING
- ORDER BY
- LIMIT
- LEFT JOIN
- Subqueries

## Business Questions Answered

1. Which customers are repeat customers?
2. Which customers placed no orders?
3. Which cities have the most active customers?
4. Which customers are one-time vs repeat customers?
5. Which customers placed more orders than the average customer?

## SQL Concepts Demonstrated

- Customer classification using CASE
- Aggregation with COUNT and AVG
- Filtering grouped results with HAVING
- Finding top-performing groups using ORDER BY and LIMIT
- Comparing results against averages using subqueries
