# SQL 

A collection of SQL projects focused on data analysis, data manipulation, and database querying. These projects demonstrate my hands-on experience with SQL through different datasets and practical exercises.

## Projects

### 1. SQL Product Analysis
Analyzes product data to explore pricing, product categories, colors, and styles.

**Concepts:** `SELECT`, `WHERE`, `DISTINCT`, `ORDER BY`, `GROUP BY`, `HAVING`, and aggregate functions.

### 2. SQL Data Manipulation
Explores customer and order data to analyze customer activity, repeat purchases, and ordering patterns.

**Concepts:** `SELECT`, `LEFT JOIN`, `CASE`, `GROUP BY`, `HAVING`, and subqueries.

### 3. SQL JOIN Analysis
Practices combining data from related tables to retrieve and analyze information across multiple datasets.

**Concepts:** SQL joins and relational database queries.

### 4. Spotify Song Analysis
Analyzes Spotify music data to explore song energy, danceability, tempo, musical keys, and listening preferences.

**Concepts:** Aggregate functions, `CASE`, subqueries, `GROUP BY`, and window functions including `RANK()`, `DENSE_RANK()`, `ROW_NUMBER()`, `LAG()`, and `LEAD()`.
