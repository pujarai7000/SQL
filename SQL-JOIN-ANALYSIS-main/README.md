# SQL JOIN Analysis

## Project Overview

This project demonstrates SQL JOIN operations and data aggregation using customer and order datasets.

## Skills Practiced

- INNER JOIN
- LEFT JOIN
- NULL handling
- COUNT()
- GROUP BY
- HAVING
- ORDER BY

## Business Questions Answered

1. Show customer names and products ordered.
2. Show customer name, city, order ID, and product.
3. Show all customers and their products, including customers with no orders.
4. Show only customers who have never placed an order.
5. Count orders per customer.
6. Count orders per city.
7. Show customers with more than one order.
8. Show customers and order counts from highest to lowest.
